M. Manjunathan — EPUB Accessibility Portfolio

FILES
- index.html: responsive, single-page portfolio website.
- README.txt: these instructions.

HOW TO PREVIEW
1. Extract the ZIP file.
2. Open index.html in Chrome, Edge, or Firefox.

HOW TO PUBLISH FOR A SHAREABLE URL
Option A — GitHub Pages:
1. Create/sign in to a GitHub account.
2. Create a public repository, e.g. manjunathan-portfolio.
3. Upload index.html and this README.
4. In repository Settings > Pages, select deploy from the main branch and root folder.
5. Save and wait for GitHub Pages to provide the public URL.

Option B — Netlify:
1. Sign in to Netlify.
2. Use its manual deploy / drag-and-drop option to upload the extracted folder.
3. Copy the published URL once the deployment completes.

BEFORE PUBLISHING
- Check all dates, tools, award details, and contact details.
- The project examples are labelled as demonstration projects. Do not imply they are paid client projects.
- Do not upload confidential client or employer files.
- Consider removing the phone number from the public website if you prefer email-only contact.
- Do not claim full WCAG conformance based only on ACE or WAVE scans; combine automated findings with manual review.
