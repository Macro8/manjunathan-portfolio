Selected sample projects

Demonstration work designed to show approach, checks, and reporting style. Replace or supplement these with sanitized examples you personally create and can share.

01 · EPUB accessibility review

Goal: Review a sample EPUB for common accessibility and usability concerns.

Workflow: Run ACE by DAISY, inspect flagged findings, review document structure and navigation, then manually check reading order and key interactions.

Deliverable: A prioritized issue log with issue, location, impact, evidence, and suggested remediation.

EPUB 3ACEManual review

02 · Screen-reader QA checklist

Goal: Check whether a sample publication can be navigated and understood with assistive technology.

Workflow: Use JAWS and NVDA to review headings, links, tables, image alternatives, reading order, and navigation landmarks where applicable.

Deliverable: A repeatable test checklist with pass, fail, not applicable, and notes.

JAWSNVDAQA

03 · Web content accessibility scan

Goal: Identify common accessibility issues on a sample web page or local demo page.

Workflow: Use WAVE to review detected errors, alerts, contrast indicators, headings, and form labels, then verify findings manually.

Deliverable: A concise findings report separating tool-detected issues from manual observations.

WAVEWCAG conceptsReporting

04 · EPUB production quality audit

Goal: Build a final-check process for a sample EPUB before delivery.

Workflow: Verify table of contents, links, metadata, content order, typography, image display, internal references, and validation results.

Deliverable: A final audit checklist and a defect summary grouped by severity.

My review process

1. Understand

Confirm publication type, expected output, project specifications, and acceptance criteria.

2. Validate

Run appropriate automated checks and inspect structural, content, and rendering issues.

3. Test manually

Review keyboard access and screen-reader behavior where applicable; verify findings rather than relying on tools alone.

4. Report & recheck

Document clear reproduction steps, prioritize defects, verify corrections, and record final status.
